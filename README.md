# 🔒 友好的程序

一个全屏置顶的窗口，要求输入密码才能退出，否则无法关闭。适用于恶作剧或临时锁定屏幕。

## ✨ 功能

- **全屏置顶**：窗口覆盖整个屏幕，始终在最前
- **禁止关闭**：点击关闭按钮无效，Alt+F4 等组合键也被拦截
- **密码验证**：正确密码为 `123456`（可在代码中修改）
- **成功提示**：密码正确后显示绿色提示，2 秒后自动退出
- **错误提示**：密码错误显示红色提示，可重新输入

## 🛠️ 运行环境

- Python 3
- 仅使用 Tkinter（标准库）

## 🚀 快速开始

## 1. 退出方法
- 输入正确密码：在输入框中输入 123456，点击“确认”按钮
- 强制退出：在任务管理器中结束 Python 进程，或使用 Ctrl+Alt+Delete 注销系统

## 2.📖 代码说明
- `root.attributes('-fullscreen', True)` 使窗口全屏
- `root.attributes('-topmost', True)` 让窗口始终在最前
- `root.protocol("WM_DELETE_WINDOW", disable_event)` 拦截关闭窗口事件
- 密码正确后，窗口会在 2 秒后自动调用 `root.destroy()` 退出

## 3.⚙️ 自定义
- 修改密码：将 `correct_password = "123456"` 中的字符串改为你想要的新密码
- 修改提示文字：修改对应 `Label` 的 `text` 属性
- 调整窗口大小：修改 `geometry("600x450")` 参数（全屏模式下通常无影响）

## 4.⚠️ 注意事项
- 本程序仅供学习娱乐，请勿用于恶意锁屏他人电脑
- 如果忘记密码，需要通过系统任务管理器强制结束进程
